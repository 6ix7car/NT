# 📝 Система заметок — инструкция пользователя

[![Version](https://img.shields.io/badge/version-1.0.0-brightgreen)](https://github.com/6ix7car/NotesSystem/releases)
[![.NET Framework](https://img.shields.io/badge/.NET%20Framework-4.8-blue)](https://dotnet.microsoft.com/)

**Консольная система для администрирования IT-инфраструктуры VPN-сервиса.**  
Позволяет вести заметки, отслеживать загрузку серверов (CPU/RAM/HDD), просматривать логи безопасности и автоматически обновляться.

## 🧩 Архитектура

Проект состоит из трёх независимых компонентов:

| Компонент | Назначение |
|-----------|------------|
| **Launcher.exe** | Проверяет обновления на GitHub, скачивает новую версию (распаковывает на рабочий стол) и запускает остальные приложения. |
| **NotesApp.exe** | Основное приложение: управление заметками, мониторинг сервера, логи безопасности. |
| **StatsAgent.exe** | Фоновый агент: каждую минуту собирает статистику (CPU, RAM, HDD) и сохраняет в базу данных. |

## 🔐 Аутентификация

| Команда | Описание | Пример |
|---------|----------|--------|
| `--login (-login) <username> <password>` | Вход в систему | `--login admin mypass` |
| `--register (-reg) <user> <pass> [role]` | Регистрация пользователя. Роли: `admin`, `user`, `readonly` (по умолчанию `user`) | `--register john 12345 user` |
| `--myrole (-role)` | Показать роль текущего пользователя | `--myrole` |
| `--logout (-out)` | Выход из системы | `--logout` |

## 📝 Работа с заметками

> **Примечание по ролям:**  
> - `admin` и `user` — могут создавать, редактировать, удалять и восстанавливать заметки.  
> - `readonly` — могут только просматривать заметки (`--listNotes`, `--getNote`).

| Команда | Описание | Пример |
|---------|----------|--------|
| `--addNewNote (-a, -add) "<текст>"` | Создать новую заметку | `--addNewNote "Проверить сервер БД"` |
| `--listNotes (-l, -list)` | Показать все свои заметки | `--listNotes` |
| `--getNote (-g) <id>` | Показать заметку по ID | `--getNote 5` |
| `--editNote (-e, -edit) <id> "<новый текст>"` | Редактировать заметку | `--editNote 5 "Новый текст"` |
| `--deleteNote (-d, -del, -rm) <id>` | Удалить заметку (мягкое удаление) | `--deleteNote 5` |
| `--restoreNote (-r, -restore) <id>` | Восстановить удалённую заметку | `--restoreNote 5` |

## 📊 Мониторинг системы (только для роли `admin`)

| Команда | Описание | Пример |
|---------|----------|--------|
| `--systemStats (-stats) local` | Показать статистику текущего сервера (CPU, RAM, HDD) и сохранить в БД | `--systemStats local` |

> *Примечание:* удалённая статистика (`remote`) пока находится в стадии разработки.

## 📋 Логи безопасности (только для роли `admin`)

| Команда | Описание | Пример |
|---------|----------|--------|
| `--securityLogs (-logs) list` | Показать последние 20 записей логов безопасности | `--securityLogs list` |

## 🔄 Обновления

Обновления проверяются **при запуске лаунчера** (команда внутри основного приложения `--checkUpdate` отсутствует – она относится к лаунчеру).

| Команда (в лаунчере) | Описание |
|----------------------|----------|
| Автоматически при старте | Сравнивает текущую версию с последним релизом на GitHub. При наличии новой версии предлагает скачать и установить. |
| `--update` | Принудительная установка обновления (если доступно). |

## ⚙️ Установка и настройка

1. **Установите PostgreSQL** (версия 14 или выше). Создайте базу данных:
   ```sql
   CREATE DATABASE "NoteSystem";
2. Выполните SQL-скрипт для создания таблиц (файл create_tables.sql в репозитории).

3. Скачайте последний релиз с GitHub Releases и запустите Launcher.exe.

4. При первом запуске лаунчер проверит обновления (если нет интернета – просто запустит приложение).

5. Основное приложение (NotesApp.exe) предложит зарегистрировать первого пользователя (администратор).

## 🧹 Примечания
* Пароли хешируются с помощью MD5.

* При удалении заметка не стирается из базы, а помечается флагом IsDeleted = true – её можно восстановить.

* Логи безопасности сохраняются в таблицу security_logs и в текстовый файл logs\security.log.

* Для работы требуется запущенный PostgreSQL и база данных NoteSystem.
